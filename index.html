How it works

One model, two small services.

Data

Eleven habit and lifestyle fields — screen time, sleep, study load, stress, and more — collected from student self-reports.

Model

A scikit-learn regression pipeline, trained offline and saved to disk, maps those habits to a single wellbeing score.

Serving

A FastAPI endpoint loads the trained pipeline once at startup and returns a live prediction for every request — this page included.

Interface

This page is plain HTML, CSS, and JavaScript. It calls the API with fetch() and renders exactly what the model returns.

Educational tool, not a diagnosis. Mindscore produces a statistical estimate from a machine learning model trained on survey data. It is not a clinical assessment and cannot diagnose, treat, or substitute for a conversation with a licensed mental health professional. If you're struggling, please reach out to a counsellor, doctor, or a crisis line in your area.
